# ☕ Java Fundamentos

Repositório dedicado ao estudo dos fundamentos da linguagem Java, conceitos de programação orientada a objetos e resolução de exercícios práticos.

---

## 🚀 Tecnologias Utilizadas

- **Java JDK** (versão 17+ / 21 LTS)
- **Git & GitHub** para versionamento
- **IDE:** VS Code / IntelliJ IDEA

---

## 📂 Estrutura do Repositório

```text
├── src/
│   ├── Exercicio01NomeIdade.java      # Leitura de dados (nome e idade) via Scanner
│   ├── Exercicio02AreaQuadrado.java    # Cálculo de área do quadrado com Scanner e float
│   ├── Exercicio03AreaRetangulo.java   # Cálculo de área do retângulo com múltiplos inputs
│   └── Exercicio04DiferencaIdade.java  # Operações matemáticas e diferença entre idades
└── README.md
```
## 📌 Conteúdos Praticados
Entrada e saída padrão (System.in, System.out.println, System.out.printf)

- Manipulação da classe java.util.Scanner

- Tipos de dados primitivos e inferência de tipos (var, int, float, String)

- Formatação de saída com máscaras (%s, %d, %.2f)

- Operações aritméticas e funções matemáticas (Math.abs)
